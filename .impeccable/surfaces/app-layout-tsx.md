Visitor mode: Persuade (site shell and cover). The styleguide is Operate, inside the same world.

Audience: a family on a phone deciding whether to trust this company with a Char Dham trip.
Job: believe this is an Uttarakhand specialist, then inquire — never book.
Proof: regional specificity in the form itself; no invented prices, testimonials, or route-open claims.
Constraints: token CSS only, WCAG AA, mobile-first, `prefers-reduced-motion`, Core Web Vitals.

## Direction contract

THESIS: The site is a Haridwar yatra booklet, not a mountain-hero travel template. Marigold cover, then newsprint pages.

OWN-WORLD: Marigold cover stock, cool gray-green newsprint, blue-black offset ink, sindoor stamp for the one action, deodar pine for the footer. Rasa titles; Atkinson Hyperlegible body. Bound plates, not lifted cards.

STORY: This company knows these mountains. Inquire for a quote.

FIRST VIEWPORT: Saffron header and cover as one sheet. Wordmark left, contents-list nav. Rasa title. One sentence of the offer. Stamp-red primary action. Interior routes drop to newsprint.

FORM: Yatra booklet (seed f1bf1fb7). Raises: one plate, one statement; cover loud / interior quiet; next action as the cover band; duration as folio marks later; confirmation as written receipt.

Challenger verdicts: airport wayfinding competitive on clarity (kept the next-action band). Glazier, dream-fold, neon, jackfield, phosphor declined; kept plate bounds, quiet interiors, numbered marks, written states.
